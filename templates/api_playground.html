Integration notes

Move from testing to production

  • Use the HTTPS integration guide for TLS termination, proxy headers, stable secrets, and same-origin rules.
  • Use the server-side /api/info request from your own backend. Browser requests from another origin are rejected; do not disable CSRF or add permissive CORS.
  • Import the repository's Postman collection to test health and metadata requests with a configurable baseUrl.
  • This service is rate-limited and accepts public media URLs. Respect platform terms and content permissions.
